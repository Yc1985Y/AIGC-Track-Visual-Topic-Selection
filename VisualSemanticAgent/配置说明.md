## 4. local.properties

当前工程根目录下的 `local.properties` 至少要包含：

```properties
sdk.dir=E\:\\AndroidSDK
```

如果要接 vivo 真机接口，再补：

```properties
VLM_APP_ID=你的AppID
VLM_API_KEY=你的AppKey
```

说明：

- `local.properties` 是本地文件，不应上传仓库。
- 当前这台机器上，已验证只写 `sdk.dir` 也可以完成构建；如果要调用真实模型，则必须补 `VLM_APP_ID` 和 `VLM_API_KEY`。

## 5. 如何打开 App

### 方式 A：用 Android Studio 打开工程

1. 启动：

```powershell
& 'E:\Program Files\Android\Android Studio\bin\studio64.exe'
```

2. 在 Android Studio 中打开工程目录：

`D:\桌面\本科\课题all\中国高校计算机大赛AIGC赛道\VisualSemanticAgent`

3. 确认 Gradle JDK 指向：

`E:\AIGC\tools\jdk17\jdk-17.0.19+10`

4. 运行目标选择：

- 模拟器：`VSA_API34_GOOGLE`

5. 点击运行 `app`

### 方式 B：命令行构建并安装

先设置环境：

```powershell
$env:JAVA_HOME='E:\AIGC\tools\jdk17\jdk-17.0.19+10'
$env:ANDROID_HOME='E:\AndroidSDK'
$env:ANDROID_SDK_ROOT='E:\AndroidSDK'
$env:Path="$env:JAVA_HOME\bin;E:\AndroidSDK\platform-tools;E:\AndroidSDK\emulator;$env:Path"
```

进入工程：

```powershell
Set-Location 'D:\桌面\本科\课题all\中国高校计算机大赛AIGC赛道\VisualSemanticAgent'
```

构建：

```powershell
.\gradlew.bat :app:assembleDebug
```

### 启动模拟器

```powershell
& 'E:\AndroidSDK\emulator\emulator.exe' -avd VSA_API34_GOOGLE
```

### 安装 APK

```powershell
& 'E:\AndroidSDK\platform-tools\adb.exe' -s emulator-5554 install -r 'D:\桌面\本科\课题all\中国高校计算机大赛AIGC赛道\VisualSemanticAgent\app\build\outputs\apk\debug\app-debug.apk'
```

### 启动 App

```powershell
& 'E:\AndroidSDK\platform-tools\adb.exe' -s emulator-5554 shell monkey -p com.vsa.visualsemanticagent -c android.intent.category.LAUNCHER 1
```

如果需要显式指定 Activity，也可用：

```powershell
& 'E:\AndroidSDK\platform-tools\adb.exe' -s emulator-5554 shell am start -n com.vsa.visualsemanticagent/.MainActivity
```
