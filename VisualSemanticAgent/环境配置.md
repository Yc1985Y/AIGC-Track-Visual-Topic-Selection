# 织时工程环境配置

这份文档是当前《织时》Android 工程的统一接手入口。
后续每次继续本项目时，先读取本文件，再进行构建、运行、修改、测试和提交。

## 1. 工程身份

- 作品全称：织时：将校园信息碎片整合为专属时间线的智能助手
- 桌面 App 名称：织时
- Android 包名：`com.vsa.visualsemanticagent`
- 启动 Activity：`com.vsa.visualsemanticagent.MainActivity`
- Gitee 仓库：`https://gitee.com/hr0503/vivo.git`
- 当前仓库根目录：`E:\AIGC\vivo\vivo`
- Android 工程目录：`E:\AIGC\vivo\vivo\VisualSemanticAgent`

## 2. 本机环境

### JDK

- JDK 路径：`E:\AIGC\tools\jdk17\jdk-17.0.19+10`
- 必须使用：JDK 17

PowerShell 临时设置：

```powershell
$env:JAVA_HOME='E:\AIGC\tools\jdk17\jdk-17.0.19+10'
$env:Path="$env:JAVA_HOME\bin;$env:Path"
```

### Android SDK

- SDK 路径：`E:\AndroidSDK`
- `adb`：`E:\AndroidSDK\platform-tools\adb.exe`
- `emulator`：`E:\AndroidSDK\emulator\emulator.exe`

PowerShell 临时设置：

```powershell
$env:ANDROID_SDK_ROOT='E:\AndroidSDK'
$env:ANDROID_HOME='E:\AndroidSDK'
$env:Path="E:\AndroidSDK\platform-tools;E:\AndroidSDK\emulator;$env:Path"
```

### 模拟器

- AVD 名称：`VSA_API34_GOOGLE`
- 常用设备序列号：`emulator-5554`

启动命令：

```powershell
& 'E:\AndroidSDK\emulator\emulator.exe' -avd VSA_API34_GOOGLE -no-snapshot-load
```

## 3. vivo AIGC 配置

- 聊天接口：`https://api-ai.vivo.com.cn/v1/chat/completions`
- OCR 接口：`https://api-ai.vivo.com.cn/ocr/general_recognition`
- 模型：`Volc-DeepSeek-V3.2`

本地凭据写在 `local.properties`，不要提交到仓库：

```properties
sdk.dir=E\:\\AndroidSDK
VLM_APP_ID=你的AppID
VLM_API_KEY=你的AppKey
```

## 4. 常用命令

### 构建 Debug

```powershell
$env:JAVA_HOME='E:\AIGC\tools\jdk17\jdk-17.0.19+10'
$env:ANDROID_SDK_ROOT='E:\AndroidSDK'
$env:ANDROID_HOME='E:\AndroidSDK'
$env:Path="$env:JAVA_HOME\bin;E:\AndroidSDK\platform-tools;E:\AndroidSDK\emulator;$env:Path"

& 'E:\AIGC\vivo\vivo\VisualSemanticAgent\gradlew.bat' :app:assembleDebug --stacktrace
```

### 安装 APK

```powershell
& 'E:\AndroidSDK\platform-tools\adb.exe' -s emulator-5554 install -r 'E:\AIGC\vivo\vivo\VisualSemanticAgent\app\build\outputs\apk\debug\app-debug.apk'
```

### 启动 App

```powershell
& 'E:\AndroidSDK\platform-tools\adb.exe' -s emulator-5554 shell am start -n com.vsa.visualsemanticagent/.MainActivity
```

### 查看日志

```powershell
& 'E:\AndroidSDK\platform-tools\adb.exe' -s emulator-5554 logcat -d | Select-String -Pattern 'com\.vsa\.visualsemanticagent|AndroidRuntime|FATAL EXCEPTION'
```

## 5. 提交约定

这一条必须严格执行：

- 不允许提交“快照提交”、“空提交”、“占位提交”。
- 每次提交都必须是完整工程提交。
- 所谓“完整工程提交”至少满足以下条件：
  - 相关代码已写完，不是半成品。
  - `:app:assembleDebug` 构建通过。
  - 新 APK 已安装到模拟器或设备。
  - 至少完成本次改动对应的一轮核心功能验证。
  - 如涉及文档、进度、作品描述，需要同步更新。

提交前默认检查顺序：

1. 读取本文件。
2. 确认仓库目录和工程目录正确。
3. 确认 JDK 17 和 Android SDK 环境正确。
4. 执行 `:app:assembleDebug`。
5. 安装并运行 App。
6. 完成本次改动的最小回归验证。
7. 再提交到 Gitee。
