# 进度说明

更新日期：`2026-05-06`

## 当前定位

项目当前不再按“医院辅助”方向描述，而是统一定位为：

> **移动端视觉-动作操作系统（Visual-to-Tool OS）原型**

更具体地说，它是一个运行在手机端的 **Agent Middleware OS**，负责把“拍照 / 语音 / 文字输入”转成“结构化语义理解 + 风控判定 + Android 系统动作执行”。

当前主展示方向是通用的跨应用视觉任务，而不是单一行业场景。

## 当前主展示链路

现在最适合对外展示的四条链路是：

### 1. 海报 / 通知 -> `create_event`

- 识别活动标题、时间、地点
- 展示确认卡片
- 拉起日历写入待确认事件

### 2. 地点信息 -> `navigate`

- 提取楼栋、教室、会场等地点
- 展示导航确认
- 调起地图应用

### 3. 联系方式 / 铭牌 -> `send_sms`

- 提取电话号码和沟通要点
- 强制进入短信草稿模式
- 不允许自动发送

### 4. 长文本 -> `tts_feedback`

- 对长通知、复习资料、菜单等做信息压缩
- 输出适合播报的摘要
- 直接进行 TTS 反馈
